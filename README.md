# Yisen Li — Academic Homepage

Source for [yisen03-explosion.github.io](https://yisen03-explosion.github.io), built with Jekyll and hosted on GitHub Pages.

Based on the [acad-homepage](https://github.com/RayeRen/acad-homepage.github.io) template (MIT License), with layout adapted from [Hao E. Zhang's homepage](https://haozhang-thu.github.io).

## Editing

- Sidebar (name, photo, links): `_config.yml`
- Page content (About, Research, News, Publications, Education, Experience): `_pages/about.md`
- Top navigation: `_data/navigation.yml`
- Images and GIFs: `images/`

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000.
